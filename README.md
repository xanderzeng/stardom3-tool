# 明星志愿 3 实时助手

这是一个只读内存仪表盘，面向 Steam 版《明星志愿 3 Deluxe》。当前版本实时显示：

- 游戏日期与星期
- 艺人姓名、性别、签约状态，以及角色对玩家的好感度
- 演技、口才、歌艺、名气、仪态、动感、体能、才智、自信
- 压力、疲劳、叛逆、性感、亲和、人气、曝光与成功值
- 当前由旗下艺人参与、尚未结束的通告
- 各制作单位目前仍有空缺角色的招募通告
- 通告档期、制作单位、角色难度、属性门槛与已安排艺人
- 通告制作人姓名及其对玩家的好感度
- 公司概览实时显示翱翔天际的资金、知名度、已签约艺人与当前拥有的物品
- 通告卡片支持折叠，并读取通告简介及影视剧角色内容
- 通告页支持按类型筛选，并依据 v8.01 事件备忘录“日程模板”显示本周与下周的通告轮换类型
- 翱翔天际作为玩家自有公司，制作人好感度标记为“不适用”
- 从《FlySky日记 2023简体中文版》整理的 18 位艺人及 12 类特殊事件，共 1947 条剧情资料
- 按游戏内当前日期展示本周限时剧情，仅包含已签约艺人、可签约艺人与特殊事件
- 本周提醒按剧情合并成卡片，提醒页与完整剧情查询均支持单项或批量展开、收起
- 日历提醒包含每年 2 月与 8 月买药、8 月 8 日探望金父，以及情人节、圣诞节和当前已签约艺人生日的提前 14 天倒计时
- 全艺人事件浏览，可按艺人、剧情类别和关键词定位查询
- 页面右上角提供整体放大后的小、中、大三档字号设置；剧情卡片默认收起

攻略中的前置事件、场景、通告、好感度和选择分支仍需玩家结合当前进度确认。

## 使用

1. 启动游戏并读取存档。
2. 双击 `Stardom3Assistant.exe`。
3. 浏览器会打开 `http://127.0.0.1:36733/`，数据每秒刷新。

工具只申请 Windows 的 `PROCESS_VM_READ` 与进程查询权限，不包含写内存功能。若游戏和工具的权限级别不同，请让二者都以普通用户运行，或都以管理员运行。

## 开发运行

```powershell
dotnet run -- --no-browser
```

## 构建单文件

```powershell
dotnet publish -p:PublishProfile=Windows-x64
```

发布结果位于 `dist\win-x64\Stardom3Assistant.exe`。该版本为 Windows x64
单文件自包含程序，目标电脑无需另外安装 .NET 运行时。
