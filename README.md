这是一个面向 Steam 版《明星志愿 3 Deluxe》的 Windows 桌面辅助工具。程序以只读方式读取游戏进程中的当前存档数据，并结合整理后的攻略资料，集中展示艺人属性、公司状态、通告、剧情查询和本周事件提醒。

程序不会修改游戏内存，也不包含自动操作、数值修改或存档修改功能。

## 主要功能

### 游戏状态与日期

- 自动寻找正在运行的 `Stardom3.exe` 并读取当前存档状态。
- 实时显示游戏日期和星期，数据默认每秒刷新一次。
- 游戏尚未启动或未读取存档时，会显示等待连接状态。
- 工具与游戏应使用相同权限级别运行，例如都使用普通用户权限，或都使用管理员权限。

### 艺人属性

- 可选择仅查看已签约艺人，或查看全部可读取艺人。
- 支持按艺人姓名或 ID 搜索。
- 显示姓名、性别、签约状态、角色对玩家的好感度及累计赠礼次数。
- 已签约艺人可展开“送礼好感度”，按 +5 至 +1 查看 90 种参考物品中对该艺人有效的礼物。
- 显示演技、口才、歌艺、名气、仪态、动感、体能、才智和自信；数值按游戏界面的整数点数显示，与通告门槛保持同一量级。
- 显示压力、疲劳、叛逆、性感、亲和、人气、曝光和成功值。
- 属性表会持续刷新；横向或纵向滚动后，刷新不会再使表格跳回起始位置。

### 公司概览

- 显示玩家公司“翱翔天际”的当前资金。
- 显示公司知名度和已签约艺人数量。
- 显示当前拥有的物品、物品类型、效果与数量；可赠送物品同步列出所有已签约艺人的好感度增量，实时刷新时保留库存表滚动位置。

### 通告

- 使用“正在招人”和“当前拥有”两个子分页管理通告，默认优先展示正在招人的通告，标签会显示各自数量。
- 两个子分页内均按电影、电视剧、唱片、广告等通告类型集中分组，并显示每组数量。
- 当前拥有的通告仅包含有旗下艺人参与、尚未完全结束的项目。
- 招募通告显示各制作单位目前仍有空缺的角色。
- 支持按照通告类型筛选。
- 支持一键展开或收起当前筛选结果中的全部通告卡片。
- 每张通告卡片可展开或收起，并显示：
  - 通告名称、类型、子类型和当前状态；
  - 内容简介；
  - 制作公司；
  - 制作人及其对玩家的好感度；
  - 签约、开工和完成日期；
  - 角色名称、难度、能力门槛、已安排艺人和角色简介。
- 广告、影视剧及其他能够读取到角色资料的通告都会展示相应角色内容。
- 正在招募的角色会按男女性别限制筛选旗下艺人，逐项比较当前属性与通告门槛，并优先显示达标程度较高的候选人。
- “翱翔天际”是玩家自有公司，因此制作人好感度显示为“不适用”。
- 根据 v8.01 事件备忘录的“日程模板”，显示本周与下周轮换的通告类型；轮换以周日为每周更新边界，每周范围为周日至周六。

### 时间轴

- 汇总所有带有明确日期范围的艺人剧情和特殊事件，按游戏日期从早到晚排列。
- 默认展示全部剧情的关键时间节点，也可筛选指定艺人或指定特殊事件。
- 时间节点显示日期范围、所属对象、剧情分类、事件编号、触发类型和完整事件内容。
- 每个时间轴节点可直接勾选完成；勾选后会自动完成此前节点、记录当前游戏日期，并停留在操作节点所在月份。
- 已完成节点和已错过剧情会同步显示相应状态，并支持直接切换剧情进度存档槽位。
- 打开时间轴、切换筛选对象或游戏日期变化时，会自动定位到当前游戏月份；当月没有节点时定位到最近的后续月份。
- 当前游戏日期仍处于触发期限内的节点会高亮显示。
- 当前置节点带有完成日期时，会根据“上个事件后／事件 N 后若干天、周、月内”等条件推算相对期限，并作为“前置完成后限时”节点加入时间轴；超过期限的未完成节点会标记为期限已过。
- 时间轴工具栏会在页面滚动时固定在顶部，并提供一键回到页面顶部的按钮。
- 可通过月份栏直接定位指定月份，切换剧情范围后会保留目标月份。
- 支持仅展示已收藏艺人或特殊事件的时间节点，也可隐藏已标记错过的剧情。
- 窄窗口下时间轴会自动改为单列布局。

### 本周提醒

- 根据游戏当前日期筛选本周具有时间限制的剧情节点。
- 提醒范围包括：
  - 当前已签约艺人的限时剧情；
  - 仍处于签约期限内的可签约艺人剧情；
  - 特殊事件和日历提醒。
- 事件按整段剧情合并成卡片展示，卡片默认收起，并支持全部展开或全部收起。
- 每个当前提醒节点会同步展示同段剧情的上一节点和下一节点内容；位于剧情开头或结尾时会明确提示“第一个节点”或“最后一个节点”。
- 可在“进行中”和“全部可触发剧情”之间切换，并分别显示对应数量。
- 对存在前置节点的剧情，会结合已完成标记判断当前节点是否满足前置条件。
- 前置节点完成后产生的相对限时节点，如果推算出的期限与本周相交，也会自动加入本周提醒。
- 已标记为“错过”的整段剧情不会继续出现在本周提醒中。
- 窄窗口下会自动切换为单列卡片，标题、状态和操作区域会自动换行。

内置的固定日历提醒包括：

- 每年 2 月和 8 月提醒购买药品；
- 每年 8 月 8 日父亲节事件提前一周提醒前往公园看望金父；
- 2 月 14 日、12 月 25 日和当前已签约艺人的生日提前两周提醒。

### 全部剧情查询

- 攻略数据整理自《FlySky日记 2023简体中文版》。
- 当前收录 18 位艺人和 12 类特殊事件，共 1985 条按展示口径整理的剧情资料。
- 六大特殊国际通告分别作为六段独立剧情展示。
- “美丽之星”按第一年、第二年和第三年拆成三段独立剧情，分别展示当年的初选门槛、决选门槛、名气要求和举办地点；各年度的完成与错过标记互不影响。
- 可按艺人或特殊事件类型切换查询。
- 可通过剧情下拉框快速定位同一角色下的具体剧情。
- 同一段剧情的所有节点合并在一张卡片中，不拆成多个零散区块。
- 支持按事件编号、类型、剧情名称和正文关键词搜索。
- 支持按整段剧情状态筛选：
  - **进行中**：至少完成一个节点，但尚未完成全部节点；
  - **已完成**：该段剧情的全部节点均已完成；
  - **未开始**：尚未完成任何节点。
- 可选择是否显示已经标记为错过的剧情。

### 剧情完成与错过标记

- 每个剧情节点都可单独勾选完成。
- 勾选完成时会记录当前读取到的游戏日期，并在节点旁显示“完成于 YYYY-MM-DD”；旧版已有标记因没有历史日期，会显示“日期未记录”。
- 剧情节点按时间顺序排列；完成某个节点时，会自动完成它之前的节点。
- 勾选节点、整段完成或剧情错过后会保留当前卡片的展开状态，避免操作时自动收起。
- 每张剧情卡片支持一次勾选整段完成或取消整段完成。
- 卡片会显示“已完成节点数 / 总节点数”，并通过不同边框状态区分未开始、进行中、已完成和已错过。
- 可把整段剧情标记为“剧情已错过”；错过后会从本周提醒中排除，也可在全部剧情查询中取消该标记。

这些标记仅用于辅助工具内部记录，不会写入游戏存档，也不会自动判断游戏是否真正触发过该剧情。

### 剧情收藏

- 可使用艺人或特殊事件类型旁的 `☆` 收藏当前对象，收藏后显示为 `★`。
- 收藏星星采用无边框图标样式。
- 已收藏对象会在选择列表中显示星标。
- 艺人事件列表会将已收藏艺人置顶，并在收藏组和未收藏组内按游戏艺人 ID 升序排列。
- “只看收藏”可仅显示已收藏的艺人和特殊事件类型，并显示当前收藏数量。
- 收藏结果自动保存到本地，关闭并重新打开程序后仍会保留。

### 本地剧情进度存档

- 提供 5 个可自由命名的本地存档槽位。
- 每个槽位会保存当前的节点完成标记、对应游戏日期和剧情错过标记。
- 支持保存、读取和删除槽位，也可只清空当前标记而保留已保存槽位。
- 收藏属于工具偏好设置，不随剧情进度槽位切换。

### 桌面窗口

- 主分页栏在页面滚动时始终吸附于窗口顶部；时间轴筛选栏会固定在主分页栏下方，滚动时间轴时可随时切换功能分页。
- 双击 EXE 后直接显示独立 Windows 程序窗口，不会自动打开外部浏览器或显示本地网址。
- 支持最小化、最大化、调整窗口大小和记忆上次窗口位置。
- 右上角提供小、中、大三档整体字号设置，卡片内部文字会同步缩放。
- 提供“窗口置顶”按钮，可让工具保持在其他窗口上方，并记忆上次置顶状态。
- 关闭程序窗口后，内部本地服务会同步退出。

## 数据来源

- 游戏实时数据：只读访问当前运行的《明星志愿 3 Deluxe》进程。
- 全艺人与特殊事件剧情：《FlySky日记 2023简体中文版》整理资料。
- 通告类型轮换：v8.01《明星志愿3事件备忘录模板共享.xlsx》的“日程模板”。
- 送礼好感度：MISAE Game Life《明星志愿3 物品好感度表》（资料录自官方攻略本，仅供参考）。

攻略资料中的前置场景、通告条件、属性门槛、好感度要求和选择分支仍需玩家结合当前游戏进度确认。工具展示的剧情完成与错过状态以玩家手动标记为准。

## 使用方法

1. 启动 Steam 版《明星志愿 3 Deluxe》并读取一个游戏存档。
2. 双击 `Stardom3Assistant.exe`。
3. 等待窗口顶部显示已连接游戏，之后数据会每秒自动刷新。
4. 如果始终无法连接，请确认游戏与工具的权限级别一致。

## 本地数据

窗口设置、剧情标记、剧情进度槽位和收藏数据均保存在当前 Windows 用户的本地应用数据中。桌面版使用的 WebView2 数据目录位于：

```text
%LOCALAPPDATA%\Stardom3Assistant\
```

这些数据不会上传到网络。删除该目录会同时清除工具的窗口设置、本地剧情进度和收藏记录。

早期浏览器版本中保存的剧情标记不会自动迁移到桌面版的数据目录。

## 运行环境

- Windows x64；
- Steam 版《明星志愿 3 Deluxe》；
- Microsoft Edge WebView2 Runtime。现代 Windows 通常已经包含该组件；若程序提示缺失，请先安装 WebView2 Runtime。

发布版是 Windows x64 单文件自包含程序，目标电脑无需另外安装 .NET 运行时。

## 开发运行

```powershell
dotnet run -- --no-browser
```

`--no-browser` 会仅启动内部本地服务，适合开发和界面调试，不会显示桌面窗口。

## 构建单文件 EXE

```powershell
dotnet publish -p:PublishProfile=Windows-x64
```

发布结果位于：

```text
dist\win-x64\Stardom3Assistant.exe
```
